# Hackathon Radar — persistent state

Files:
- `constraints.md`  — hard filters + PASS/FAIL/UNKNOWN rule (source of truth)
- `sources.md`      — Phase 1 source ecosystem (where opportunities appear)
- `leads.md`        — raw leads, NOT yet verified (no lead is a candidate until verified from the official page)
- `tool-radar.md`   — capability gaps + tools/skills/scripts we build or adopt

Evidence labels: PASS = supported by evidence, FAIL = incompatible, UNKNOWN = insufficient evidence.
UNKNOWN is never silently upgraded to PASS. Every claim carries a source URL + date checked.
